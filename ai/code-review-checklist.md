# AI 代码审查清单

## 架构
- [ ] 是否遵守模块边界？
- [ ] 是否把业务逻辑错误放进 Handler / Repository？
- [ ] 是否引入不必要的依赖或复杂度？

## 安全
- [ ] 是否从可信上下文获取 tenant_id / app_id？
- [ ] 是否存在跨租户访问可能？
- [ ] 是否泄漏 Secret、Token 或敏感内容？
- [ ] 文件访问是否进行授权？

## 数据
- [ ] 是否有正确索引和唯一约束？
- [ ] 是否有 Migration？
- [ ] 并发写入是否安全？
- [ ] 事务边界是否明确？

## 消息
- [ ] 重试是否幂等？
- [ ] 是否先持久化再 ACK？
- [ ] seq 是否原子分配？
- [ ] Outbox 消费是否可重复？
- [ ] 接收端是否先落库再 Delivered ACK？
- [ ] 离线同步是否可补偿缺失消息？

## 测试
- [ ] 正常路径、错误路径和边界路径是否覆盖？
- [ ] 并发和重复请求是否覆盖？
- [ ] 测试是否实际执行并报告结果？
