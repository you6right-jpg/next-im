# ADR-0001：总体架构基线

- 状态：Accepted
- 日期：2026-11-19

## 背景
项目目标是构建商业化 IM 平台，需要兼顾 SaaS、私有化、多端 SDK 和后续水平扩展，同时控制初期开发复杂度。

## 决策
- Go 服务端。
- 模块化单体起步，保留服务拆分边界。
- HTTP + WebSocket。
- Protobuf 统一协议。
- MySQL 业务持久化，Redis 缓存与路由。
- Outbox + Kafka 异步事件。
- S3 兼容对象存储。
- SaaS 和私有化共用核心代码。
- 从第一天纳入 tenant_id / app_id。

## 后果
初期部署组件数量可控，但模块接口、数据所有权和事件契约必须设计清晰。Kafka / Kubernetes 等基础设施可按阶段引入，不应阻塞最初的核心链路。
