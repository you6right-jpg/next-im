# 测试策略与验收

## 服务端
- 单元测试：领域规则、状态机、权限。
- 集成测试：MySQL、Redis、Outbox。
- API 测试：参数、鉴权、错误码。
- WebSocket 测试：协议、心跳、断连。
- 并发测试：幂等、seq 分配、群发。
- 多租户测试：跨租户访问拒绝。
- 故障测试：节点重启、依赖不可用。
- 压测：连接数、消息吞吐、延迟和恢复。

## SDK
- 登录 / 登出。
- 断网重连。
- 发送重试和去重。
- 消息顺序和缺口补偿。
- 离线同步。
- 多设备。
- 本地数据库迁移。
- 撤回和已读。
- 文件上传失败重试。
- 前后台切换和进程重启。

## 跨端一致性
建立共享测试场景，验证不同 SDK 的 message_id、conversation_id、seq、状态流转和错误语义一致。

## 发布门槛
- CI 通过。
- 关键模块测试通过。
- 无未解释的高危安全问题。
- Migration 已验证。
- API / 协议变更有兼容说明。
- 部署、回滚和监控说明齐全。
