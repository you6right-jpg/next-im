# 安全基线

## 身份认证
- AppID 用于识别应用，AppSecret 不下发给普通终端。
- 用户 Token 有过期、刷新、撤销机制。
- 设备维度支持会话撤销和踢下线。
- 服务间通信使用身份认证。
- 管理后台采用 RBAC，敏感操作二次确认或审批。

## 租户隔离
- 请求认证后建立可信 TenantContext / AppContext。
- 不信任客户端传入的 tenant_id 作为授权依据。
- Repository 查询必须使用上下文中的租户条件。
- Redis Key、Kafka Event、对象存储 Key 均带租户 / 应用命名空间。
- 文件下载必须验证文件所属租户和访问权限。
- 自动化测试覆盖跨租户读写攻击。

## 数据安全
- 全链路 TLS。
- 数据库和对象存储启用静态加密能力。
- Secret 放 Secret Manager / 环境 Secret，不入 Git。
- 日志脱敏，禁止记录凭证和敏感内容。
- 支持数据备份、恢复、导出和删除策略。
- 审计日志防篡改并设置保留周期。

## 端到端加密
传输加密、静态加密和 E2EE 是不同能力。若产品要求 E2EE，应采用经过公开审查的成熟协议和实现，不自行设计密码算法。E2EE 会影响服务端搜索、内容审核、消息预览和多设备密钥同步，需独立设计。
