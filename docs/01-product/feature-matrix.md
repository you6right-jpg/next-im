# 功能矩阵与优先级

优先级表示建设顺序，不代表最终产品只实现 P0。

| 域 | 功能 | 优先级 |
|---|---|---|
| 平台 | Tenant / App / AppID / AppSecret | P0 |
| 认证 | 登录、Token 刷新、注销、设备认证 | P0 |
| 连接 | WebSocket、心跳、连接路由、多设备 | P0 |
| 消息 | 单聊文本、幂等、持久化、ACK、分发 | P0 |
| 同步 | 离线同步、历史消息、游标、断线恢复 | P0 |
| 会话 | 会话列表、最后消息、未读数 | P0 |
| SDK | iOS 核心 SDK、本地存储、Demo | P0 |
| 社交 | 好友、申请、黑名单 | P1 |
| 群组 | 创建、成员、角色、禁言、公告 | P1 |
| 消息状态 | Delivered、Read、撤回 | P1 |
| 文件 | 上传凭证、对象存储、下载授权 | P1 |
| 推送 | APNs、FCM、厂商推送适配 | P1 |
| 集成 | Webhook、服务端回调 | P1 |
| 管理 | 用户、群组、设备、审计管理 | P1 |
| 多端 | Android、Flutter、Web SDK | P1 |
| 搜索 | 用户、群组、消息搜索 | P2 |
| 商业化 | 套餐、用量、账单、License | P2 |
| 规模化 | Kafka 消费扩展、服务拆分、K8s | P2 |

## 版本发布原则

每个版本必须有：
- 明确功能范围和不包含范围。
- 数据库迁移说明。
- API / 协议变更说明。
- SDK 兼容性说明。
- 自动化测试报告。
- 部署和回滚说明。
