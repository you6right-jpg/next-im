# 产品概述

## 1. 产品定位

Next-IM 是面向企业和开发者的商业级即时通讯基础设施。交付的不只是聊天应用，而是可被第三方业务系统集成的 IM 服务端、跨平台 SDK、管理后台和开放平台。

## 2. 目标交付物

- Go IM 服务端：用户、设备、连接、消息、会话、好友、群组、同步、文件、推送、Webhook、管理和计费能力。
- iOS SDK：Swift，支持 Swift Package / XCFramework 交付。
- Android SDK：Kotlin，支持 Maven 依赖。
- Flutter SDK：Dart Plugin，首期桥接 iOS / Android 原生 SDK。
- Web SDK：TypeScript / npm。
- 管理后台：平台运营和企业管理员使用。
- 开放平台：应用创建、密钥管理、API 文档、Webhook、用量和账单。
- 部署工具：Docker、Kubernetes 部署模板、迁移和升级工具。
- Demo：各端集成示例。

## 3. 部署形态

### SaaS
平台统一运营，多租户共享基础设施，通过 `tenant_id`、`app_id`、权限校验和数据访问层实现逻辑隔离。

### 私有化
客户独立环境部署，可采用独立数据库、Redis、对象存储和消息队列。提供 License、离线安装包、升级迁移、监控和诊断能力。

两种模式共享核心代码、协议和 SDK，不维护两套业务实现。

## 4. 用户角色

- 平台超级管理员：管理租户、集群、套餐、授权和全局运营。
- 租户管理员：管理租户应用、用户、群组、配置和审计。
- 应用开发者：管理 AppID、凭证、Webhook、SDK 和 API。
- 终端用户：使用集成 IM 的业务产品。
- 私有化运维人员：部署、升级、备份、监控和故障处理。

## 5. 功能范围

### 核心 IM
认证、设备、连接、单聊、群聊、会话、消息同步、历史消息、消息状态、撤回、已读回执。

### 扩展能力
好友、黑名单、群管理、图片、语音、视频、文件、位置、名片、自定义消息、搜索、审核、推送。

### 平台能力
多租户、多应用、开放 API、Webhook、管理后台、审计、用量统计、套餐、计费、License。

## 6. 非目标与边界

- 不把 APNs / FCM 当作消息可靠传输通道。
- 不在第一阶段自行设计密码学协议。
- 不在初期将所有模块拆成微服务。
- 不承诺未经压测验证的连接数、吞吐量或延迟指标。
- 不把媒体文件二进制直接存入消息主表。
